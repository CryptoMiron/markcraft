# S1b — Внешние изменения

Выход среза: если файл изменили вне MarkCraft, об этом сообщают, автосейв
останавливается, пользователь выбирает «перечитать» или «оставить своё».

## Шаги

1. `notify` на каталог файла, фильтр по имени.
2. Своя запись тоже даёт событие — глушим по времени/размеру, чтобы не пугать себя.
3. Диалог: «Файл изменён на диске» → Перечитать / Оставить моё.
   «Перечитать» выбрасывает правки в редакторе, «Оставить моё» — нет.
4. Пока диалог открыт, автосейв на паузе (флаг `asking` уже есть).

## Проверка

```sh
./target/release/markcraft /tmp/a.md &   # открыть
echo "правка снаружи" >> /tmp/a.md       # изменить
# ожидание: диалог, файл не перезаписан, правки в редакторе целы
```
