# S2 — Рендер

Выход среза: markdown перестаёт быть текстом и становится документом
с типографикой Inkdown; маркеры видны только там, где стоит курсор.

**Почти закрыт 2026-10-25.** Открыт R2.3 — подсветка кода внутри блока, вынесена в S2b.

## Что внутри

Редактор — CodeMirror 6 в системном WebKitGTK, без сетевых запросов.

| Слой | Файл | Что делает |
|---|---|---|
| Разметка | `ui/links.js` | адрес ссылки под курсором; 6 тестов |
| Движок | `ui/editor.js` | CM6, `@lezer/markdown` + GFM, декорации |
| Типографика | `ui/style.css` | числа из `docs/TYPOGRAPHY.md` |
| Сборка | `bin/bundle` | bun → один `ui/built.html` (779 KB) + вкомпилирование |

`ui/built.html` коммитится, чтобы `cargo build` работал без bun. `bin/check`
пересобирает его и падает, если закоммиченная версия разошлась с исходниками.

## Правила живого превью

1. **Маркер виден только на активной строке.** Курсор в абзаце — в абзаце видны
   `**`, `*`, `~~`, `` ` ``, скобки ссылки; в остальном документе они скрыты.
2. **Блочные виджеты** (таблица, `---`) заменяют блок целиком и кликом ставят
   курсор в его начало.
3. **Ограда кода** скрывается вместе с переводом строки, чтобы не оставалось
   пустой строки; строки кода получают фон и моноширинный шрифт.
4. **Задачи**: дефис и `[ ]` заменяются чекбоксом.
5. **Сырой HTML** остаётся текстом: это редактор, а не браузер.
6. **Шапка файла** (frontmatter между `---` в первой строке) — это YAML, а не
   разметка: рисуется блоком кода, внутри неё Markdown не разбирается.

## Три ловушки

**Блочные декорации нельзя отдавать из `ViewPlugin`.** CM6 падает с
`RangeError: Block decorations may not be specified via plugins`. Таблицы и `---`
живут в `StateField` — он это разрешает.

**Стили CM6 инжектятся после наших.** При равной специфичности побеждает поздний,
и редактор оставался моноширинным: `.cm-scroller` из CM6 перебивал наш
`.cm-scroller`. Лечится специфичностью предка — `.cm-editor .cm-scroller`.

**Без `<meta name="viewport">` WebKitGTK включает shrink-to-fit.** При узком окне
страница масштабируется целиком вместо перестройки строк: буквы те же по высоте,
но сжаты по ширине, а координаты мыши перестают совпадать с позициями текста —
курсор и выделение на перенесённых строках не работают. Лечится одной строкой в
`ui/template.html`: `width=device-width, initial-scale=1`.

## Проверка

```sh
./bin/bundle
cargo build --release
./target/release/markcraft fixtures/gfm-full.md   # посмотреть глазами: блоки, отступы, подсветка
bin/check                                          # fmt, clippy, cargo test, bun test, свежесть built.html
```

Регресс байтовой верности после переезда с `<textarea>` на CM6 — 10 фикстур, `cmp` чист.
