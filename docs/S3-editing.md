# S3 — Правка

Выход среза: редактором можно пользоваться, не заглядывая в markdown руками.

**Готово 2026-10-25.**

## Что умеет

| Действие | Поведение |
|---|---|
| Enter в `- пункт` | продолжает `- `, отступ сохраняется |
| Enter в `1. пункт` | продолжает `2. `, номер растёт |
| Enter в `- [x] задача` | продолжает `- [ ] ` (новая — невыполненная) |
| Enter в `> цитата` | продолжает `> ` |
| Enter в пустом пункте | убирает маркер, выходит из списка |
| Tab / Shift+Tab | вложенность на 2 пробела / обратно |
| Ctrl+B, Ctrl+I, Ctrl+Shift+X | оборачивают выделение, повторное нажатие снимает |
| Ctrl+B без выделения | оборачивает слово под курсором |
| Ctrl+K | `[выделение](https://)` с курсором на адресе |
| Ctrl+K внутри ссылки | выделяет адрес, чтобы набрать новый |
| Ctrl+V | вставка через GTK-буфер |

Правила лежат в `ui/editing.js` — отдельно от редактора, поэтому проверяются
тестами без окна. 29 тестов в `ui/editing.test.js`.

## Три бага, которые здесь поймались

**1. Ctrl+Z сразу после открытия стирал файл.** Транзакция загрузки документа
попадала в историю CM6: первый же Ctrl+Z откатывал её в пустой документ,
а автосейв через 1.2 с записывал пустоту на диск. Это была потеря данных
в один жест. Лечится `Transaction.addToHistory.of(false)` при загрузке;
проверяется тремя тестами в `ui/history.test.js` через `undoDepth(state)`.

**2. Вставка не работала вообще.** WebKit под Wayland не обрабатывает
синтетический Ctrl+V (и Ctrl+C тоже — буфер не меняется). Полагаться на
поведение браузера нельзя: Ctrl+V теперь идёт в Rust, читает
`gtk::Clipboard::wait_for_text()` и отдаёт текст обратно в редактор.
Побочная польза: вставка HTML всегда даёт текст.

**3. Ctrl+K внутри ссылки плодил вложенные.** `[т[текст](https://)екст](https://)`.
Теперь `existingLink()` находит ссылку вокруг курсора и выделяет адрес.

## IME

Блочные виджеты (таблица, `---`) не пересобираются, пока идёт composition:
иначе замена DOM под курсором рвёт ввод и съедает первый слог. Состояние
держит `composingField`, `compositionstart`/`compositionend` его переключают.

**Не проверено:** настоящий IME (fcitx5) синтетическими клавишами не
воспроизводится — `wtype` отправляет готовые символы, а не composition-события.
Нужен живой человек за клавиатурой с русской/китайской раскладкой. Это
единственный открытый риск среза.

## Как проверять

```sh
./bin/bundle && cargo build --release
./target/release/markcraft fixtures/gfm-full.md
bin/check     # 32 bun-теста, 6 cargo-тестов, свежесть built.html
```

Проверка через живое окно — `wtype` + `hyprctl dispatch hl.dsp.focus`.
