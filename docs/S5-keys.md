# S5 — Клавиши и поиск

Выход среза: клавиатурой можно всё, что нужно, и ничего не приходится искать мышью.

**Готово 2026-10-26.**

## Что появилось

| Клавиша | Что делает |
|---|---|
| Ctrl+F | поиск, подсветка всех совпадений |
| Ctrl+H | то же с полем замены |
| Enter / Ctrl+G / Shift+Enter | дальше / дальше / назад |
| Esc | закрыть панель |
| Ctrl+= / Ctrl+- / Ctrl+0 | размер текста, 10% за шаг |
| Ctrl+колесо | то же |
| Ctrl+N | новое окно (отдельный процесс) |
| Ctrl+Shift+C | документ как HTML + markdown запасным |
| Ctrl+? / Ctrl+/ / F1 | справка по клавишам |

**Полноэкранный режим не реализуется.** Это глобальный хоткей Omarchy: приложение
не должно перехватывать то, что решает композитор. В справке так и написано.

## Масштаб текста

Три множителя: база 16 px × системный `text-scaling-factor` × пользовательский
`zoom`. Пользовательский лежит в `$XDG_STATE_HOME/markcraft/zoom` и переживает
перезапуск. Колонка растёт вместе с текстом: при 1.2 она 840 px, иначе в строку
влезает меньше знаков, чем задумано.

## Поиск по-русски

Панель CM6 берёт строки из `EditorState.phrases`: «дальше», «назад», «все»,
«с учётом регистра», «слово целиком», «заменить все». Стили панели — из тех же
CSS-переменных, что и документ, поэтому она не выпадает из темы Omarchy.

## Ловушка: `dispatch` у команд поиска

`replaceAll(view)` вызывает `view.dispatch(spec)`, где `spec` — **описание
транзакции**, а не готовая транзакция. Наивный тест с
`dispatch: (tr) => (state = tr.state)` получает `undefined` и падает.
Правильно: `dispatch: (spec) => (state = state.update(spec).state)`.

`replaceNext` в тестах не работает вовсе: ему нужен настоящий `EditorView`
с панелью (`view.plugin`), а в bun без DOM его нет. Поэтому одиночная замена
проверяется мышью, а «заменить все» — тестом на реальном состоянии.

## Проверено

- Ctrl+F → ввод → подсветка двух совпадений, Enter ведёт ко второму.
- Ctrl+H → панель с полем замены и кнопками.
- Ctrl+= ×2 → `zoom` = 1.2; Ctrl+0 → 1.0.
- Ctrl+Shift+C → `wl-paste -t text/html` отдаёт `<h1>Заголовок <em>с курсивом</em></h1>`,
  `wl-paste` — исходный markdown.
- Ctrl+? → диалог справки.
- Ctrl+N → второй процесс и второе окно.
