# MarkCraft — SPEC v1

Единственный список требований. Пункт не считается сделанным, пока не отмечен здесь
и не проверен руками. Новое требование сначала попадает сюда, потом в код.
Всё, чего здесь нет, — не делается (см. CUTS.md).

## 0. Инварианты (не обсуждаются в срезах)

- **I1. Файл — источник истины.** В памяти всегда ровно тот текст, который будет записан.
- **I2. Никакой сериализации AST → markdown.** Функции `toMarkdown` в проекте нет.
- **I3. Сохранение без правок возвращает файл байт-в-байт** (CRLF, BOM, табы, хвостовые пробелы, отсутствие финального перевода строки, юникод).
- **I4. Один бинарник, ноль сетевых запросов.** Шрифты, CSS, JS вкомпилированы.
- **I5. Метрики — из Inkdown, палитра — из Omarchy.** Своих настроек темы и шрифта нет.
